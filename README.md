# Café Kamaro

Website institucional para distribuidora de cafés especiais.

## Desenvolvimento

As páginas utilizam HTML, CSS e PHP (PHPMailer) para o formulário de contato.

Configure as variáveis de ambiente `MAIL_USERNAME` e `MAIL_PASSWORD` para enviar e-mails pelo formulário.

## Estrutura

- `index.html` – página principal
- `about.html` – sobre a empresa
- `service.html` – qualidade e serviços
- `menu.html` – catálogo de produtos
- `reservation.html` – solicitação de orçamento
- `contact.html` – formulário de contato
